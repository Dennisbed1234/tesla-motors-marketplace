# Vehicle images

Upload your files into this folder:

- `cybertruck.png` — Cybertruck AWD primary image
- `cybertruck2.png` — Cybertruck Cyberbeast (or second angle)
- Optional: `roadster.png`, `model-3.png`, etc.

Then point Neon image URLs to:

```
/images/cybertruck.png
/images/cybertruck2.png
```

On Vercel these are served from `public/images/` automatically.
